간행물 올리기

여기서 정보를 입력하면 GitHub 저장소에 자동으로 올라갑니다. 코드를 직접 만질 필요 없습니다.

1. 연결 설정

최초 1회만 입력하면 됩니다. 이 페이지를 닫지 않는 한 브라우저에 기억해둡니다.

토큰이 뭐고 어떻게 만드나요?
이 도구가 여러분 대신 GitHub 저장소에 파일을 올리려면 "허락 열쇠"가 필요합니다.

1. github.com에서 우측 상단 프로필 사진 클릭 → Settings
2. 맨 아래 Developer settings 클릭
3. Personal access tokens → Fine-grained tokens → Generate new token
4. Repository access에서 "Only select repositories" 선택 → kmwuhhi 저장소만 체크
5. Permissions → Repository permissions → "Contents"를 Read and write로 설정
6. Generate token 클릭 → 나오는 토큰(ghp_로 시작)을 복사해서 위 칸에 붙여넣기

이 토큰은 이 브라우저 탭에만 저장되고, 서버로 전송되지 않습니다(GitHub에 직접 요청을 보낼 때만 사용). 아무에게도 공유하지 마세요.

2. 새 간행물 정보

사진 또는 PDF를 여기로 끌어놓거나 클릭해서 선택하세요
(JPG, PNG, PDF · 여러 장 선택 가능, PDF는 1개만)

3. 기존 글 관리

올린 글의 제목/날짜/카테고리를 고치거나, 잘못 올린 글을 지울 수 있습니다.

4. 홈 화면 박스(카테고리) 관리

메인 화면에 뜨는 박스 종류와 순서를 바꿀 수 있습니다.
